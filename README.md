# PBLJ-FS_634_A

This repository contains Java class experiments and practice programs created as part of coursework.  
It primarily includes:

- **Student_AttendanceSystem**: A project folder with refactored database connection structure.
- **Experiment Files**: Individual Java files (`Exp. 2.2(a)`, `Exp. 2.2(b)`, `Exp. 2.2(c)`) showcasing different class-based experiments.

## Purpose
The repository is intended for academic learning and demonstration of Java programming concepts.  
It serves as a collection of experiments rather than a full production-ready application.

## Structure
- `Student_AttendanceSystem/` → Attendance system project with DB connection refactor.
- `Exp. 2.2(a).java` → Class experiment (part a).
- `Exp. 2.2(b).java` → Class experiment (part b).
- `Exp. 2.2(c).java` → Class experiment (part c).
